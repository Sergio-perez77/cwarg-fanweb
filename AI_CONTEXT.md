# Charlotte Wessles Argentina Fanweb

## Project
Independent fan website for Charlotte Wessels Argentina.

## Objetive
Build an editorial fan website with public previews, authenticated full articles, comments, user playlists, music/video playback and an administration panel.

## Technology
- Next.js
- Typescript
- Tailwind CSS
- Supabase
- Github
- Vercel

## Roles
- Super Admin
- Admin
- Registered User
- Public Visitor 

## Core Features
- Public homepage
- Public articles previews
- Full articles available to authenticated users
- User registration and login
- comments
- User-created playlist
- Music and video library
- Custom media player
- Super Admin and Admin dashboard
- User management
- Content management
- Branded loading screen
- Legal notices and privacy policy

## Development Rules
- Keep changes minimal and focused.
- Never modify files outside the requested scope.
- Explain every file created, modified or deleted.
- Provide complete code for proposed file changes.
- Never expose Supabase secrets or credentials.
- Never disable security policies to fix errors.
- Preserve existing working functionallity.
- Ask before making destructive changes.
- Document dependencies and commands.
- Do not assume permissions to copyrighted media.
